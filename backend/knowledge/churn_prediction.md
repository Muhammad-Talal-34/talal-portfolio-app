# Customer Churn Prediction Engine

A predictive analytics tool that evaluates customer retention signals to help flag churn risk.

## Tech stack
Python, Django, XGBoost, scikit-learn, and pandas.

## Key features
- Comparative model benchmarking across Logistic Regression, Random Forest, and XGBoost
- A trained model serialized and exported for real-time web inference
- Django integration handling customer attribute ingestion and risk scoring

No final accuracy or benchmark numbers are confirmed — don't state a specific figure unless verified.
